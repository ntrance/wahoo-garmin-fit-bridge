Help & Multi-Platform Sync Guide

⚡ How Garmin Edge Emulation & Watch Physio TrueUp Work

Garmin Connect normally accepts third-party FIT uploads but refuses to calculate Training Load, Acute Load, Recovery Time, or VO2 Max for your Garmin watch unless the file claims to be from a Garmin device.

Physical Head Units (Karoo / COROS / Wahoo / iGPSPORT)

The bridge rewrites the FIT header to an emulated Garmin Edge 1040 (Product 3907, Unit ID 3991000001). Garmin Connect treats the ride as recorded on a genuine Garmin head unit, syncing all physiological load metrics down to your Garmin watch.

Virtual Trainers (Zwift / MyWhoosh / TrainingPeaks Virtual)

The bridge rewrites the header to a Garmin Edge 1040 while preserving sub_sport: 27 (Virtual Activity). In Garmin Connect, the activity displays as an indoor Virtual Ride while still giving your watch full TSS, VO2 Max, and Training Load.

💻 Windows PC Setup (Zwift / MyWhoosh / ROUVY / TrainingPeaks)

Virtual cycling apps automatically save your completed ride .fit files to local folders on your computer (e.g. Documents\Zwift\Activities).

ℹ️ What this command is doing: The mklink /J command creates a live folder link (Directory Junction). It connects your app's local activities folder directly into your Dropbox folder. Your files are not moved or duplicated on your hard drive, but Dropbox instantly sees any newly saved ride and syncs it to the bridge without you needing to drag or copy files.

Step-by-step setup:

  1. Install the official Dropbox Desktop App on your PC so you have a local Dropbox folder.
  2. Open Command Prompt as Administrator (Search for cmd in the Start Menu, right-click, and select Run as administrator).
  3. Run the command for your training application:
mklink /J "%USERPROFILE%\Dropbox\Apps\WahooFitness\Zwift" "%USERPROFILE%\Documents\Zwift\Activities"
mklink /J "%USERPROFILE%\Dropbox\Apps\WahooFitness\MyWhoosh" "%USERPROFILE%\Documents\MyWhoosh"
mklink /J "%USERPROFILE%\Dropbox\Apps\WahooFitness\Rouvy" "%USERPROFILE%\Documents\ROUVY"
mklink /J "%USERPROFILE%\Dropbox\Apps\WahooFitness\TPVirtual" "%USERPROFILE%\Documents\TrainingPeaks Virtual\Activities"
✅ Done: As soon as you hit "End Ride" in your virtual app, Windows links the .fit file into Dropbox, the bridge detects it, converts the header to Garmin Edge 1040 (with virtual activity tagging preserved), and uploads it to Garmin Connect!
🍎 Mac / macOS Setup (Zwift / MyWhoosh)

On macOS, virtual training apps save .fit files to your user Documents folder (e.g. ~/Documents/Zwift/Activities/).

ℹ️ What this command is doing: The ln -s command creates a symbolic link (live folder alias) between the app's local activity folder and your Dropbox sync folder. Every new ride file is automatically seen by Dropbox and uploaded by the bridge without manual file copying.

Step-by-step setup:

  1. Install the official Dropbox Desktop App for Mac.
  2. Open the Terminal app (press Cmd + Space, type Terminal, and hit Enter).
  3. Run the command for your training application:
ln -s ~/Documents/Zwift/Activities ~/Dropbox/Apps/WahooFitness/Zwift
ln -s ~/Documents/MyWhoosh ~/Dropbox/Apps/WahooFitness/MyWhoosh
✅ Done: Any virtual ride finished on your Mac automatically syncs straight into Dropbox and uploads to Garmin Connect.
🚴 Hammerhead Karoo (1, 2, 3) Setup

Because Karoo runs on Android, it saves completed ride .fit files to /sdcard/FitFiles/.

Automatic Wi-Fi Folder Sync via Dropsync:

  1. Install Dropsync (Autosync for Dropbox) on Google Play ↗ (or sideload its APK onto your Karoo).
  2. Open Dropsync and link your Dropbox account.
  3. Set up the Sync Folder Pair:
    • Local device folder: /sdcard/FitFiles/
    • Remote Dropbox folder: Apps/WahooFitness/Karoo (or Apps/WahooFitness)
    • Sync method: Upload only
    • Sync trigger: Automatic when connected to Wi-Fi.
💡 Done: When you finish an outdoor ride and Karoo connects to your home Wi-Fi or phone hotspot, Dropsync immediately uploads the Karoo .fit file to Dropbox. The bridge processes it and uploads to Garmin Connect as a Garmin Edge 1040 activity!
⌚ COROS (Watches & DURA Bike Computers) Setup
Native Cloud-to-Cloud Sync (Recommended):

The bridge includes a direct COROS Cloud API Source that connects straight to your COROS account in the background:

  1. Go to Config and toggle on COROS Cloud.
  2. Enter your COROS account email and password, select your account region, and click Save COROS profile.
  3. Click Test COROS login to verify connection.
✅ Done: The moment your COROS watch or DURA finishes syncing to the COROS app on your phone, the bridge automatically detects the new workout, downloads the .fit file, rewrites the device header, and pushes it to Garmin Connect!
Alternative Manual 1-Tap Share from COROS App:

Open any activity in the COROS phone app ➔ tap Share ➔ Export Data ➔ FIT ➔ save to Dropbox (Apps/WahooFitness/COROS).

📁 Local Folder Watcher (NAS / Local Server)

If you prefer not to use cloud accounts and run the bridge on a home server (Unraid, Synology, TrueNAS), map any local network directory directly to /data/incoming in Docker: 

volumes:
  - /path/to/my/fit_folder:/data/incoming
  - ./data:/data
  - ./appdata:/appdata
🔐 Garmin Two-Factor Authentication (MFA) & Terminal Login

If your Garmin account has 2-Factor Authentication (2FA) enabled or if you are running the bridge on a cloud server/VPS, Garmin may send a 6-digit one-time code to your email when authenticating.

Option 1: Web Browser UI

In Config ➔ Garmin Upload, enter your Garmin email & password. If Garmin requires MFA, a verification box will appear asking for the 6-digit code sent to your email. Enter it and click Verify & Complete Setup.

Option 2: Terminal / Docker CLI Login

If you prefer to log in interactively from the command line on your server, run: 

docker compose run --rm -it bridge wahoo-bridge-garmin-login
ℹ️ Note: Once your Garmin session token is saved to /appdata/garmin/tokens, the bridge automatically refreshes it in the background. You do not need to re-enter MFA codes for subsequent uploads.
