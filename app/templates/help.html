Help & Multi-Platform Sync Guide

⚡ How Garmin Edge Emulation & Watch Physio TrueUp Work

Garmin Connect normally accepts third-party FIT uploads but refuses to calculate Training Load, Acute Load, Recovery Time, or VO2 Max for your Garmin watch unless the file claims to be from a Garmin device.

Physical Head Units (Karoo / COROS / Wahoo / iGPSPORT)

The bridge rewrites the FIT header to an emulated Garmin Edge 1040 (Product 3907, Unit ID 3991000001). Garmin Connect treats the ride as recorded on a genuine Garmin head unit, syncing all physiological load metrics down to your Garmin watch.

Virtual Trainers (Zwift / MyWhoosh / TrainingPeaks Virtual)

The bridge rewrites the header to a Garmin Edge 1040 while preserving sub_sport: 27 (Virtual Activity). In Garmin Connect, the activity displays as an indoor Virtual Ride while still giving your watch full TSS, VO2 Max, and Training Load.

💻 Windows PC Setup (Zwift / MyWhoosh / Rouvy)

Virtual cycling apps save .fit files locally to your PC Documents folder:

  • Zwift: %USERPROFILE%\Documents\Zwift\Activities
  • MyWhoosh: %USERPROFILE%\Documents\MyWhoosh

Automatic 1-time setup (Windows Directory Junction):

  1. Install the official Dropbox Desktop App on your PC.
  2. Open Command Prompt as Administrator (cmd.exe).
  3. Run this command:
mklink /J "%USERPROFILE%\Dropbox\Apps\WahooFitness\Zwift" "%USERPROFILE%\Documents\Zwift\Activities"
✅ Done: The moment you finish a ride in Zwift, Windows mirrors the .fit file to Dropbox. The bridge processes it and uploads to Garmin automatically.
🍎 Mac / macOS Setup (Zwift / MyWhoosh)

On macOS, Zwift and MyWhoosh save .fit files to:

  • ~/Documents/Zwift/Activities/

Automatic 1-time setup (macOS Symlink):

  1. Install the official Dropbox Desktop App for Mac.
  2. Open the Terminal app.
  3. Run this command:
ln -s ~/Documents/Zwift/Activities ~/Dropbox/Apps/WahooFitness/Zwift
✅ Done: Any virtual ride finished on your Mac automatically syncs straight into Dropbox and uploads to Garmin Connect.
🚴 Hammerhead Karoo (1, 2, 3) Setup

Because Karoo runs on Android, it saves .fit files to /sdcard/FitFiles/.

Automatic Wi-Fi Folder Sync:

  1. Install a background sync app (like FolderSync or Autosync for Dropbox) on your Karoo.
  2. Set the sync pair:
    • Local folder: /sdcard/FitFiles/
    • Remote Dropbox folder: Dropbox/Apps/WahooFitness/Karoo
    • Trigger: Automatic on Wi-Fi connection.
💡 When you finish an outdoor ride and Karoo connects to Wi-Fi/Hotspot, the ride auto-syncs to Dropbox -> Bridge -> Garmin Connect.
📁 Local Folder Watcher & COROS
Direct Folder Watcher (NAS / Local Host)

If you prefer not to use Dropbox, map any local/NAS folder into /data/incoming in Docker: 

volumes:
  - /path/to/my/fit_folder:/data/incoming
  - ./data:/data
  - ./appdata:/appdata
COROS DURA & Watches

Export .fit files from COROS Training Hub into your linked Dropbox folder (Apps/WahooFitness/COROS) or local incoming folder.
